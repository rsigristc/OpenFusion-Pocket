# Contributing

Bug reports, device testing, code reviews and focused fixes are welcome.

For a bug report, include the release version, Android version, device/GPU, selected server, exact reproduction steps and expected/actual behavior. For world or combat issues, include the map/zone, mission, weapon and NPC name when relevant. Attach a short, redacted log or screenshot if it helps.

Remove passwords, cookies, tokens, account identifiers and private network details from any logs before sharing. Do not upload personal app data, downloaded game bundles, signing keys or original game executables.

Open focused pull requests that explain the behavior changed and how it was verified. See [BUILDING.md](docs/BUILDING.md) for Unity and regression checks. Device testing matters, especially for rendering, input, memory and loading changes.

Preserve upstream notices and document the provenance of any new dependency or extracted resource. AI-assisted contributions are welcome when their use is disclosed, the changes are understood and their behavior has been checked. Do not claim untested systems or devices as verified.
