# Security reporting

Do not post passwords, authentication cookies, tokens, account databases, signing keys or unredacted app-data archives in public issues.

For a suspected security vulnerability, use this repository's GitHub **Security → Report a vulnerability** feature when available. For ordinary crashes, rendering issues and gameplay bugs, use the issue tracker with sensitive information removed.

The client connects to the server selected by the user. Server operators control their own accounts, authentication endpoints and resource hosting. Report server-side account issues to that server's operators.

This is an actively developed community client. Published builds and passing regressions do not constitute a security certification.
