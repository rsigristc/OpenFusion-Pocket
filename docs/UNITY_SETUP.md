# Unity setup

The current, supported instructions are in [BUILDING.md](BUILDING.md).

Use Unity 2022.3.62f3 with Android Build Support and open `Assets/Scenes/Game.unity`. Runtime login, character selection and world loading are handled by the launcher and client. MapTest is no longer part of this project.

Early implementation notes were retained in [DEVELOPMENT_HISTORY.md](DEVELOPMENT_HISTORY.md). They describe investigation stages and may include obsolete limitations, test assumptions and setup steps.
