## Saved login

Remember Me retains the existing username option. On Android, a separate **Save password (encrypted)** checkbox opts into password persistence. Older remembered usernames do not silently enable password saving. Passwords are saved only after the actual login server confirms authentication, with an identity scoped to server ID, canonical API endpoint and account name. They are encrypted with AES-GCM and an Android Keystore AES key, with the identity bound as authenticated data. Ciphertext files live under the app's no-backup directory; no key or plaintext password is written to PlayerPrefs, logs or the project.

Unchecking password persistence removes that saved credential. Launcher Settings provides **Forget saved logins**, which removes remembered usernames and encrypted credential files. Failure to decrypt returns an empty password; unavailable secure storage does not block authentication. Normal Android updates retain credentials; reinstalling or losing the Keystore key requires entering the password again. Server refresh-token renewal is not implemented.

## Touch layouts

The overlay requires an active shard connection and a player, and rejects launcher, full loading and character-selection screens. Modal game interfaces, the layout editor and gamepad cursor release held touch actions.

Open **Touch layout editor / profiles** in launcher Game Settings or **Layout editor / profiles** under in-game Settings / Controls / Touch Controls. Drag a control and select it to adjust its size, opacity or enabled state. Classic and Controller presets and three saved slots are available. Controller uses colored A/B/X/Y action buttons, a fixed movement joystick and an optional continuous-look camera stick. Both sticks can be moved and resized. The floating movement joystick and free camera drag remain available in Classic. Positions are normalized to the available safe area and rectangles are clamped inside it, including after resizing/DS transitions.

Cancel restores the layout from before opening the editor. In-game Done retains edits in the existing Settings Apply/Cancel transaction; Apply Change or Save and Exit persists them. Launcher Save and Close persists immediately. Explicitly saving a profile slot is immediate and independent of cancelling the current layout.

## Gamepad cursor

A visible Android cursor allows the existing launcher and Legacy game interfaces to receive their usual touch actions, rather than duplicating inventory or mission logic. It activates in menus when a gamepad is connected. Left stick / directional keys move, A clicks (hold and move to drag), B goes back, and the right stick scrolls. L3 + R3 toggles manual cursor mode in the world. LB switches between the Unity and available DS companion surface. Gameplay movement/combat/camera mappings are suppressed while the pointer is active, and held synthetic touches are cancelled on focus loss, pause or mode/surface changes. Button/axis reporting still needs device testing; this is cursor navigation, not a complete geometric focus-navigation rewrite.

## Experimental Vulkan

The APK includes OpenGL ES 3 and Vulkan shaders, with OpenGL ES 3 selected by default. **Graphics API** in launcher Game Settings saves a preference for the next full app launch; it does not change renderers during an active session. Android must report Vulkan support before the preference can be enabled. The generated PocketActivity selects the requested API before Unity initializes. An unfinished initial engine startup causes the next launch to return to OpenGL. Successful initialization clears that startup marker after five seconds. This recovery only covers startup, not arbitrary later driver failures.

Vulkan is experimental. No performance gain is claimed before hardware measurements, and rendering/DS/readback coverage remains pending. Turnip drivers and frame generation are not included.
